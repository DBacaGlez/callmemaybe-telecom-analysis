# callmemaybe-telecom-analysis
Análisis completo del desempeño operativo de los operadores de la plataforma CallMeMaybe, evaluando tiempos de espera, llamadas perdidas, actividad saliente y métricas de eficiencia. Se identifican operadores ineficaces mediante criterios cuantitativos y se aplican pruebas estadísticas para validar diferencias significativas entre grupos.
